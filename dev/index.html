Bairava Engine Documentation

Bairava is an experimental 2D game engine written in Zig. These guides describe current behavior; the generated reference lists the canonical exports from @import("bairava").

Start here

  • Getting started
  • Public API reference
  • Sample game source

The engine API is in early development and is not production-ready. The getting-started guide uses the repository’s public-API sample.
