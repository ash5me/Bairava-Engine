What this shows
  - The mismatch is a compiler fusing text.c's `width += kerning * scale` and `width += xadvance * scale`, on a target
    where FMA exists. The Zig port does one rounding per operation, and Zig does not fuse by default.
  - The Linux mirror (checks/bfnt_measure_mirror.c) matched text.c with 0 mismatches only because it was built without
    FMA. It did not exercise the failing configuration.
  - The fix is build-side: build.zig compiles text.c with -ffp-contract=off at all four sites (test module, engine
    module, UI test harness, asset builder), through `text_c_flags`.

What this does not show
  - It does not run the Zig build. The build.zig edit is not compiled in the sandbox, and it is not evidence until
    `zig build test` passes on the commit that contains it. E-01 needs CI on that commit.
