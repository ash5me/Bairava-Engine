=== FONT ID WIDTH: u32 -> FontId (u64), 2026-11-18 ===

Scope. The font id that keys the glyph cache is widened from u32 to FontId (u64), as decision D-02 specifies.
The change touches GlyphKey.font, Cache.removeFont, keyOf, the resolver (resolve, resolveWithFallback, warm),
glyph_records.Options.font_id, and renderer/glyph_check.zig. The cache hash folds the high 32 bits into the
32-bit mix (hash_font / hashFont), so ids that differ only above bit 31 still spread across slots. Equality
compares the whole id, so a fold collision costs a probe and never a wrong hit.

Mirror: 2191 checks before the change, 2199 after. The eight new checks are the eight CHECK calls of
t_high_font_ids, the new mirror of the Zig test "fonts whose ids differ only above bit 31 are different fonts".
Every earlier check passes unchanged.
